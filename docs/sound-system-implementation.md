## Default Sounds (Fallback System)

**Yes, we have default sounds!** The system includes Web Audio API fallback tones for all events:

### 1. Position Opened
- **Fallback:** Two ascending tones (A4 → C#5)
- Frequencies: 440Hz → 554Hz
- Duration: ~230ms
- Type: Sine wave

### 2. Position Close: Profit
- **Fallback:** Ascending arpeggio (C-E-G major chord)
- Frequencies: 523Hz → 659Hz → 784Hz
- Duration: ~360ms
- Type: Sine wave

### 3. Position Close: Loss
- **Fallback:** Descending two-tone (minor feel)
- Frequencies: 392Hz → 311Hz
- Duration: ~320ms
- Type: Triangle wave

### 4. Liquidation
- **Fallback:** Low rumble with descending tones
- Frequencies: 200Hz → 150Hz → 100Hz
- Duration: ~600ms
- Type: Sawtooth wave

### 5. Auto-Close (Take Profit)
- **Fallback:** Same as profit (victory fanfare)
- Ascending arpeggio (C-E-G major chord)
- Frequencies: 523Hz → 659Hz → 784Hz
- Duration: ~360ms
- Type: Sine wave

**Note:** Voice lines are NOT generated by fallback - only sound effects. If custom sound files are missing, only the sound effect plays (no voice line).

## Behavior When Files Are Missing

1. **If `USE_CUSTOM_SOUNDS = true` (current setting):**
   - System attempts to play custom sound files
   - If file is missing, audio.play() fails silently
   - Voice line also fails silently if missing
   - **Result:** No sound plays (silent failure)

2. **If `USE_CUSTOM_SOUNDS = false`:**
   - System uses Web Audio API fallback tones
   - All 5 events have programmatic sound generation
   - **Result:** Fallback tones play (no voice lines)

## Architecture Decisions

1. **Direct Toggle vs Modal:** Chose direct toggle in menu for simplicity
2. **Global Sound State:** Used global variable in sounds.ts to avoid circular dependencies
3. **Callback Pattern:** Used callback in `checkTakeProfit` to trigger notifications
4. **Silent Failures:** Audio failures are caught silently to prevent console errors
5. **Dual-Mode System:** Maintained fallback system for when custom files are missing
